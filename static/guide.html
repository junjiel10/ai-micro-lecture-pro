Guide

三步做出第一支微课

不需要安装额外软件，也不需要写任何配置。会用浏览器，就会用这套系统。

输入主题

在创作台右侧写下要讲的知识点（例如「翻转课堂」）， 或者上传一份 PDF / Word / PPT / 教案作为素材。

可选：目标时长、画面比例、配色、插图开关 提示：主题越具体，内容越聚焦

点击开始制作

点击「开始制作」，系统会依次完成文档解析、知识结构化、分镜脚本、 配音配乐、画面生成、剪辑合成与质检打分。

全程自动：右侧可实时看到每一步的执行日志 耗时参考：3 分钟成片约需 2~3 分钟生成

预览与导出

成片会直接在页面里播放。可以切换字幕开关、点击分镜卡片跳转到对应画面， 满意后一键导出 MP4 与字幕文件。

可修改：对某一句旁白不满意，可单独改并只重做该镜 可复用：历史项目随时回放、重新导出
Capabilities

你可以调整哪些东西

默认全部自动，需要精细控制时再动这几项

画面比例
横版 16:9 适合电脑、投影与 B 站；竖版 9:16 适合手机端。竖版会把横向的流程与对比改成纵向排布，并重算字幕位置。
画面配色
深海蓝 / 书院青 / 晨光橙三套主题，画面与插图会整体换色。
画面配图
每一屏都自动配一张结构化插图：引语页用聚焦徽章、要点页用索引轨道、要素页用概念图、机制页用流程链、场景页用标签云、误区页用对照板、回顾页用总览环图。也可关闭，只用纯文字版式。
目标时长
2 / 3 / 4 / 6 / 8 分钟。系统会据此规划分镜数量与每段旁白的长短。
面向对象
本科生 / 高职学生 / 教师培训……填写后会体现在讲述语气与内容深度上。
背景音乐
舒缓 / 明快 / 温暖三种自动合成的配乐，音量已压到不干扰人声。

FAQ

常见问题

生成一支微课需要多久？

本机实测：3 分钟成片约需 2~3 分钟生成（含配音、画面与合成）。 主要耗时在语音合成与视频编码，不需要人工等待操作。

没有网络能用吗？

可以。语音合成会优先使用在线引擎（音质最佳），断网时自动降级到系统内置语音； 插图、画面、剪辑全部在本机完成，不依赖网络。

对生成的内容不满意怎么办？

成片预览后，点击分镜卡片上的 ✎ 可以修改任意一镜的旁白稿， 也可以整体更换配色。系统只重做受影响的那一步，其余内容复用，因此很快。

画面里的插图是怎么来的？

插图由本机程序化绘制，共有八类：概念结构图、流程链、标签云、对照板、 索引轨道、总览环图、聚焦徽章与抽象主视觉。系统会按分镜语义自动选型， 做到「每一屏都有图」，且图形里的文字全部来自你自己的脚本要点。

图中文字全部取自你自己的脚本要点，因此不会出现文字错误或凭空编造的内容。

可以做成手机上刷的竖版视频吗？

可以。在「画面比例」里选择竖版 9:16 即可。系统会重新排布版式并调整字幕位置， 不是简单地把横版裁掉两侧。

生成的视频可以商用或公开吗？

画面、插图与背景音乐均为本机程序化生成，不含第三方素材； 配音使用系统或在线语音合成服务，请按相应服务条款使用。 建议在正式发布前通读一遍旁白内容，确保表述准确。
